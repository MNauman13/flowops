# BPI Challenge 2019 reference data

[Official challenge and dataset description](https://icpmconference.org/2019/icpm-2019/contests-challenges/bpi-challenge-2019/)

[4TU dataset DOI](https://doi.org/10.4121/uuid:d06aff4b-79f0-45e6-8ec8-e19730c248f1)

The challenge reports 251,734 purchase line-item cases, 1,595,923 events and 42 activities. These are publisher counts. FlowOps has yet to verify them against the archive.

| Published XES trace field | Canonical use to verify |
| --- | --- |
| `Purchasing Document` and `Item` | Map directly to the two case-key components and preserve their text forms. |
| `Item Category` | Confirm the exact source literals that correspond to FlowOps's four flow categories. |
| `GR-Based Inv. Verif.`, `Goods Receipt` and `Item Type` | Cross-check the category. Consignment requires the item type to distinguish it from non-GR-based invoicing. |
| `concept:name` | Verify that the composite trace identifier agrees with the explicit document and item fields. |

Before activating the importer mapping, record the archive checksum and inspect the exact activity labels, event timestamp and value fields, reversal evidence and missing values. Confirm whether the source can link receipts, invoices and reversals reliably. Until that review is complete, amount-based matching for this dataset stays disabled and anonymised values stay distinct from currency amounts.
